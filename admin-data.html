📋 Supported JSON Formats:

Format 1 — Array of questions:
[{"questionText":"What is 2+2?","options":["2","3","4","5"],"correctAnswer":"4","type":"mcq"},...]

Format 2 — Object with questions key:
{"questions":[...],"title":"Optional Quiz Title"}

Format 3 — Old format (also supported):
{"question":"...","options":[...],"correct":2,"type":"mcq"} — will be auto-converted.

Format 4 — Full DB backup: Quizzes will be imported as whole quizzes.
